# Contribution_Management_System-
This is a project for a contribution management system for our local church. 
The project is a web app that can be opened by both the mobile and PC browser.
The web app will have the following features 
* Login for administrator and member.
* Ability to export and import report as csv file.
* Note the name, date, contribution name, method of payment and branch of the member.
* Show the total with each update.
* Ability to use both online and offline.
* Online backup of the data.
Other features will be added as it is being used.
